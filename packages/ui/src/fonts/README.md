# Product fonts

- Inter 4.1: https://github.com/rsms/inter/releases/tag/v4.1
- IBM Plex Sans Arabic 1.1.0: https://github.com/IBM/plex/releases/tag/%40ibm/plex-sans-arabic%401.1.0
- JetBrains Mono 2.304: https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304

Each family has a separate SIL Open Font License 1.1 file in its directory. The shipped weights match the type tokens: Inter and IBM Plex Sans Arabic 400, 500, and 600; JetBrains Mono 400. Token weight 590 uses the 600 face.
