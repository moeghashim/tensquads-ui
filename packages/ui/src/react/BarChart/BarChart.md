# BarChart

Import `BarChart`, `BarChartProps`, `BarChartPoint`, `BarChartSegment`, and `BarChartKey` from `@tensquads/ui/react`. Pass ordered points with a date label and either a numeric `value` or an array of `{ key, value }` segments. Pass `keys` to name stacked series and select `muted`, `strong`, `success`, or `danger` ink. Set `highlight` to an inclusive `[startIndex, endIndex]` range. Without a range, the last column is highlighted. Bars scale from a zero baseline. The chart includes a text summary, and its columns share one tab stop with arrow-key movement. Wrap it in `Card`; put the metric and time window in the Card subtitle.
