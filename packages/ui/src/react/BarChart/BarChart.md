# BarChart

Import `BarChart`, `BarChartProps`, `BarChartPoint`, `BarChartSegment`, and `BarChartKey` from `@tensquads/ui/react`. Pass ordered points with a date label and either a numeric `value` or an array of `{ key, value }` segments. Pass `keys` to name stacked series and select `muted`, `subtle`, `strong`, `success`, or `danger` ink. Use `subtle` for light historical comparison marks. Set `highlight` to an inclusive `[startIndex, endIndex]` range. Without a range, the last column is highlighted. A matching key's tone takes precedence over the highlight. Bars scale from a zero baseline; zero-valued segments have no visible mark. For integer data, the value axis rounds up to a nice maximum and shows three whole-number tick labels. Fractional data uses the largest point total, with a minimum axis maximum of 1, and can show fractional ticks. Pass `formatValue` to format axis ticks, accessible column names, and tooltip values, for example with a currency formatter. `formatValue` is a React-only callback and is not available in OpenUI streams. Hover or focus on a column to see its label, total, and stacked-series values in a tooltip. The chart includes a text summary, and its columns share one tab stop. Left and Right arrow keys move focus in the inherited layout direction. Points follow caller order from the inline start; pass the oldest point first for a time series. The x-axis shows every point label for up to 14 points. Longer series show the first label and every fifth label after it, with an aligned slot for every column. Wide charts scroll within their viewport. Wrap it in `Card`; put the metric and time window in the Card subtitle. Pass `locale="ar"` to localize generated labels and screen-reader copy; the default is English. OpenUI accepts the same `locale` prop.

- `points` is required. Each point has a `label` and either a `value` or `segments`.
- `keys` names stacked series and sets their tone. `highlight` selects an inclusive index range.
- `label` sets the chart's accessible name. `locale` selects generated English or Arabic copy.
