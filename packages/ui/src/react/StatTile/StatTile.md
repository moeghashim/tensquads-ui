# StatTile

Import `StatTile`, `StatTileProps`, and `StatTileDelta` from `@tensquads/ui/react`. A tile shows one headline metric. `label` and `value` are required. Add an optional `glyph`, `unit`, `delta`, `foot`, and `series`. Delta tone is `positive`, `negative`, or `neutral`; the consumer decides whether an increase is good. Delta text includes its comparison period. Use `delta: null` and a `foot` when there is no previous period. Pass `series: null` or omit it for a metric without a trend. The sparkline uses the consumer-provided metric label as its accessible name. A sparkline needs at least two points and reverses in RTL so time follows the reading direction.

Wrap tiles in a container with `className="ts-stat-grid"`. By default, this CSS grid uses six columns, then three at viewport widths of 73.75rem or less, two at 47.5rem or less, and one at 21.1875rem or less (1180, 760, and 339px with the browser's default 16px font size). Values use tabular numerals. The OpenUI definition accepts serializable numeric series and metric text. For an OpenUI tile grid inside a panel, use [Card](../Card/Card.md) with `layout: "stat-grid"`.
