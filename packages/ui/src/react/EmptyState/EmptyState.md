# EmptyState

Import `EmptyState` from `@tensquads/ui/react`. Provide a short `title`, one sentence `description`, and optionally one action element. Use it in place of content when there are no records or when filtering returns no matches. The host chooses the action that will produce data.

OpenUI accepts only `title` and `description`. Use React when the empty state needs an `action`, such as a button that clears the host's search and filters.
